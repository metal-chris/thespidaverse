Built the Web Rating. A spider-web SVG that fills proportionally to the score, with a small burst animation when a piece hit a perfect 100. Three sizes shipped together: a full version for the article page, a smaller badge for card overlays, and an inline tag for list rows.

> Update from later: this isn't rendered publicly anymore. The component is still in the codebase because the community slider uses the same shape. See the 2026-05-25 entry for the reasoning.
